# Contributing

Open an issue or discussion that names the factor, current wording or behavior,
counterexample, and evidence. A proposal to change the universal 22 should also
compare the pressure against adjacent factors and explain why an overlay or
implementation note is insufficient.

Repository changes should be small and reviewable, preserve static/no-telemetry
site behavior, keep machine-readable contracts backward compatible, and include
tests for new invariants. Do not commit credentials, private assessments, or
customer evidence.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
