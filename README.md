# 22-factor-apps organization defaults

This repository publishes the public organization profile and default community
health files for repositories in [`github.com/22-factor-apps`](https://github.com/22-factor-apps).

- [`profile/README.md`](profile/README.md) is rendered on the organization page.
- `SECURITY.md`, `CONTRIBUTING.md`, and `CODE_OF_CONDUCT.md` provide defaults when
  a repository does not need a more specific policy.
- `.github/CODEOWNERS` establishes the default review owner for this repository.

Product code and methodology content belong in their own repositories. This
repository stays limited to organization-level context and contribution policy.
